# 账号与会话功能交付说明

## 功能范围

管理控制台通过“账号与会话”入口提供当前账号改密、设备会话管理及多账号管理。界面支持中文、英文、浅色主题、深色主题和移动端布局。

## 角色与权限

账号具有管理员或只读运维角色。管理员可以管理账号、系统设置、定时任务和环境迁移。只读运维可以查看仪表盘、审计日志、定时任务及执行记录，可以修改本人密码和注销本人会话，不能读取敏感密钥或执行管理写操作。

新增账号默认选择只读运维角色。创建账号、角色切换、启停和密码重置均验证操作者当前密码。当前登录账号不能停用自身。最后一个启用的管理员不能被停用或降级，环境迁移导入同样保留这一约束。

## 会话行为

每次登录创建独立的持久化会话，有效期为二十四小时。会话列表展示客户端地址、浏览器信息、最近活跃时间、过期时间和当前会话标识。最近活跃时间最多每分钟写入一次。

注销本人当前会话需要确认，成功后退出登录。退出登录和会话撤销使对应凭证立即失效。修改本人密码后保留当前浏览器登录状态，注销其他设备会话。账号停用、角色变更和管理员重置密码撤销目标账号会话；重置本人密码时保留当前浏览器登录状态。角色变更后需要重新登录。

## 数据与部署

数据库启动时自动补齐账号角色和会话存储。既有账号保持管理员角色。升级前签发的登录凭证需要重新登录。部署配置和外部依赖没有变化。

环境迁移包保存账号角色和临时密码状态，不包含登录会话。没有角色字段的历史迁移包将账号视为管理员。导入账号后目标环境会话失效，需要重新登录。

## 验证结果

服务端全量测试、竞态检测、静态检查和生产构建通过。验证覆盖会话撤销、退出、过期、活跃时间更新、重启持久化、跨账号访问隔离、只读角色权限、敏感操作密码验证、角色变化及改密后的会话失效、并发管理员保护、历史数据库和环境迁移兼容。

浏览器验收覆盖账号创建的错误密码与正确密码分支、当前会话注销确认与退出、只读账号的导航和操作限制。桌面和三百九十像素移动端界面经过布局检查。
